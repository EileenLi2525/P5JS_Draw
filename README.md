# Instructions
To use, copy the raw code from [here](https://github.com/EileenLi2525/P5JS_Draw/blob/main/P5JS_Draw.js) and paste it into [p5.js](https://editor.p5js.org). SEE WARNING BELOW

Hold down the “e” key to erase, and hold down the “s” key to draw in a smaller pen size.
There is no undo button. :(


**IMPORTANT!** This program only works properly if you set p5.js to any version between 1.0.0 and 1.11.13 (inclusive). Any other version will cause it to break.

To change versions, either click on the cog button and go to the Library Management tab, or click on the version number that's next to the cog button.
