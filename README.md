# P5JS_Draw
A rudimentary art program, made in p5js.org.

<img width="579" height="245" alt="image" src="https://github.com/user-attachments/assets/3f4d65dc-a36d-4e85-a928-3c3f9d1ff63b" />

**  **

**IMPORTANT!** This program only works properly if you set p5.js to any version between 1.0.0 and 1.11.13 (inclusive). Any other version will cause it to break.

Hold down the “e” key to erase, and hold down the “s” key to draw in a smaller pen size.
There is no undo button. :(
